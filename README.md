## 🚀 Overview

This portfolio is not just a resume—it's an experience. Built with **React** and **TypeScript**, it features a sleek, dark-themed UI that mimics the Netflix "Who's Watching?" and "Browse" experience. It is designed to be fully responsive, accessible, and fast.

## 💻 How to Run Locally

1. **Clone the repo**:
   ```bash
   git clone https://github.com/W-govind/Netflix_style_portfolio.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the development server**:
   ```bash
   npm start
   ```
4. **Open your browser**:
   Visit `http://localhost:3000`
